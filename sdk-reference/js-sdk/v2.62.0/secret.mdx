### Secret

Module for managing E2B secrets and workload identity helpers.

Secret values are write-only: they are accepted by Secret.create
and Secret.update but never returned by any read surface.

#### Constructors

```ts
new Secret(): Secret
```

###### Returns

`Secret`

#### Methods

### create()

```ts
static create(
   name: string, 
   value: string, 
opts?: SecretCreateOpts): Promise<SecretInfo>
```

Create a new secret and its first value.

###### Parameters

| Parameter | Type | Description |
| ------ | ------ | ------ |
| `name` | `string` | name of the secret, unique within the project. |
| `value` | `string` | secret value. Write-only — never returned by the API. |
| `opts?` | `SecretCreateOpts` | connection options. |

###### Returns

`Promise<SecretInfo>`

the secret's ID, name, current version (`1` for a new secret),
metadata, and creation and update times.

### destroy()

```ts
static destroy(secret: string, opts?: ConnectionOpts): Promise<boolean>
```

Destroy a secret, making all its versions inaccessible.

###### Parameters

| Parameter | Type | Description |
| ------ | ------ | ------ |
| `secret` | `string` | secret ID or name. |
| `opts?` | `ConnectionOpts` | connection options. |

###### Returns

`Promise<boolean>`

`true` if the secret was destroyed, `false` if it was not found.

###### Returns

`Promise<boolean>`

`true` if the secret exists, `false` otherwise.

### fill()

```ts
static fill(secret: string): string
```

Format a placeholder that the runtime resolves to the secret's current
value.

This is a local formatting helper and makes no network call — it does
not check whether the named secret exists. An unknown reference fails
server-side when the placeholder is resolved.

###### Parameters

| Parameter | Type | Description |
| ------ | ------ | ------ |
| `secret` | `string` | secret name. |

###### Returns

`string`

placeholder string resolving to the secret's value.

###### Example

```ts
Secret.fill('openai-api-key')
// '${e2b.secrets.openai-api-key}'
```

### iamToken()

```ts
static iamToken(token: SandboxIamToken): SandboxIamToken
```

Define a workload identity token to pass to `iam.tokens` when creating
a sandbox.

###### Parameters

| Parameter | Type | Description |
| ------ | ------ | ------ |
| `token` | `SandboxIamToken` | workload token definition. |

###### Returns

`SandboxIamToken`

a token definition passable to `iam.tokens`.

###### Example

```ts
const sandbox = await Sandbox.create({
  iam: {
    tokens: {
      aws: Secret.iamToken({
        audience: 'sts.amazonaws.com',
        tokenType: 'JWT-SVID',
      }),
    },
  },
})
```

### list()

```ts
static list(opts?: SecretListOpts): SecretPaginator
```

List the project's secrets.

###### Parameters

| Parameter | Type | Description |
| ------ | ------ | ------ |
| `opts?` | `SecretListOpts` | connection options. |

###### Returns

`SecretPaginator`

paginator over the project's secrets. Drain it page by page:
`while (paginator.hasNext) { const secrets = await paginator.nextItems() }`.

###### Example

```ts
const paginator = Secret.list({ limit: 50 })
while (paginator.hasNext) {
  const secrets = await paginator.nextItems()
}
```

### SecretPaginator

Paginator for listing secrets.

#### Example

```ts
const paginator = Secret.list()
while (paginator.hasNext) {
  const secrets = await paginator.nextItems()
  console.log(secrets)
}
```

#### Constructors

```ts
new SecretPaginator(opts?: SecretListOpts): SecretPaginator
```

###### Parameters

| Parameter | Type |
| ------ | ------ |
| `opts?` | `SecretListOpts` |

###### Returns

`SecretPaginator`

#### Accessors

### hasNext

###### Get Signature

```ts
get hasNext(): boolean
```

Returns true if there are more items to fetch.

###### Returns

`boolean`

### nextToken

###### Get Signature

```ts
get nextToken(): undefined | string
```

Returns the next token to use for pagination.

###### Returns

`undefined | string`

#### Methods

### nextItems()

```ts
nextItems(opts?: ConnectionOpts): Promise<SecretInfo[]>
```

Get the next page of items.

###### Parameters

| Parameter | Type | Description |
| ------ | ------ | ------ |
| `opts?` | `ConnectionOpts` | per-call connection options. When provided, this call uses these options (e.g. `apiKey`, `domain`, `headers`, `requestTimeoutMs`, `signal`) instead of the ones the paginator was constructed with. Aborting a page via `signal` does not affect subsequent Paginator.nextItems calls — pass a fresh signal each call you want to be cancellable. |

###### Returns

`Promise<SecretInfo[]>`

List of items

###### Throws

Error if there are no more items to fetch. Call this method only if `hasNext` is `true`.

### httpVersion?

```ts
optional httpVersion: HttpVersion;
```

HTTP version for requests to the E2B API and to sandboxes (commands,
filesystem, PTY). `'2'` multiplexes streams over shared connections;
`'1.1'` pins them to HTTP/1.1 with one connection per concurrent
request — for example when an intermediary on the path retires or
mishandles long-lived HTTP/2 connections. Only applies in Node.

###### Default

###### Default

### retries?

```ts
optional retries: number;
```

Number of control-plane API retries for responses marked `Should-Retry: true`,
or 429/502/503/504 responses without that header. `Should-Retry: false` is
never retried. Waits for a valid `Retry-After` delta-seconds value, otherwise
exponential backoff with jitter from 100 ms to 10 s. Also retries failures
to establish the connection; network errors after the request is sent are
not retried.
A retry is skipped when its wait would exhaust the request timeout.
Retry waits use a 60-second total limit when request timeouts are disabled.
Set to `0` to disable retries. Defaults to 3 retries.

###### Default

```ts
3
```

###### Throws

InvalidArgumentError if the value is negative or not an integer

### signal?

```ts
optional signal: AbortSignal;
```

An optional `AbortSignal` that can be used to cancel the in-flight request.
When the signal is aborted, the underlying `fetch` is aborted and the
returned promise rejects with an `AbortError`.
