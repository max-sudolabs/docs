### CommandInputHandle

An ordered, long-lived input handle for a command or PTY.

#### Methods

### close()

```ts
close(): Promise<void>
```

Finish the input stream and wait for envd to acknowledge it.

###### Returns

`Promise`\<`void`\>

A promise that resolves when envd acknowledges the end of the input stream.

###### Throws

If the command or PTY does not exist.

###### Throws

If the input stream times out.

### send()

```ts
send(data: string | Uint8Array<ArrayBufferLike>): Promise<void>
```

Enqueue input for transmission in call order.

###### Parameters

| Parameter | Type | Description |
| ------ | ------ | ------ |
| `data` | `string` \| `Uint8Array`\<`ArrayBufferLike`\> | Input data to send. |

###### Returns

`Promise`\<`void`\>

A promise that resolves when the input is queued for ordered transmission.

###### Throws

If the command or PTY does not exist.

###### Throws

If the input stream times out.

###### Throws

If this handle is closed.

### streamInput()

```ts
streamInput(pid: number, opts: CommandStreamInputOpts): CommandInputHandle
```

Open a persistent input stream to a command.

Input sent through this stream is ordered relative to other `send` calls.
Use this instead of Commands.sendStdin when ordering matters; each
`sendStdin` call is a separate request. The stream sends keepalive messages
while idle.

In browsers, this requires fetch request-body streaming support (Chromium
over HTTP/2).

###### Parameters

| Parameter | Type | Description |
| ------ | ------ | ------ |
| `pid` | `number` | Process ID of the command. |
| `opts` | `CommandStreamInputOpts` | Optional stream timeout and abort signal. `timeoutMs` defaults to `STREAM_INPUT_TIMEOUT_MS` (60_000 milliseconds). |

###### Returns

`CommandInputHandle`

A handle whose `send()` method queues input in order and whose `close()` method ends the stream and waits for envd.

###### Throws

If the command does not exist, surfaced from `send()` or `close()`.

###### Throws

If the stream timeout expires, surfaced from `send()` or `close()`.

###### Example

```ts
const input = sandbox.commands.streamInput(pid)
await input.send('hello\n')
await input.close()
```

## Interfaces

### CommandRequestOpts

Options for sending a command request.

#### Extended by

- `CommandStartOpts`

#### Properties

### requestTimeoutMs?

```ts
optional requestTimeoutMs: number;
```

Timeout for requests to the API in **milliseconds**.

###### Default

```ts
60_000 // 60 seconds
```

### signal?

```ts
optional signal: AbortSignal;
```

An optional `AbortSignal` that can be used to cancel the in-flight request.
When the signal is aborted, the underlying `fetch` is aborted and the
returned promise rejects with an `AbortError`.

***

### CommandStartOpts

Options for starting a new command.

#### Properties

### background?

```ts
optional background: boolean;
```

If true, starts command in the background and the method returns immediately.
You can use CommandHandle.wait to wait for the command to finish.

### cwd?


