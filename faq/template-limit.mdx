---
title: "Is there a limit on how many templates I can create?"
sidebarTitle: Template limit
"og:image": "/images/og/generated/faq/template-limit.png"
---

No. There is no limit on the total number of [templates](/template/quickstart) you can create on your account.

The only template-related limit is on **concurrent builds**, i.e. how many template builds can run at the same time. On Hobby and Pro tiers this is 20; Enterprise is custom. See the [Plans table](/billing#plans) for the full list of limits.
